## ⬇️ Что скачать

👉 Откройте последнюю версию на странице **Releases** и скачайте файл из раздела **Assets**.

| Ваша система | Какой файл скачать |
|---|---|
| Windows 10 / 11 | `qtil.exe`: скачать и запустить, установка не нужна |

- **Не качайте** `Source code (zip)`: это исходный код, а не программа.
- **Не нужны** Rust и терминал. Это только для разработчиков (см. [Сборка](#-сборка-из-исходников)).
- Если Windows пишет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**: программа не подписана сертификатом.
- Q-Tiler работает в фоне и слушает горячие клавиши. Выход: <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Q</kbd>.

## 🗺️ Бесконечный холст

Нажмите <kbd>Alt</kbd>+<kbd>C</kbd>, и все открытые окна окажутся на одном безграничном поле. Двигайте пространство, меняйте масштаб от 25 до 200% и расставляйте окна как угодно.

<p align="center">
  <img src="assets/canvas.svg" alt="Бесконечный холст с окнами" width="90%">
  <br>
  <sub>Окна на холсте. Подсвеченное окно «живое»: оно работает как обычное приложение.</sub>
</p>

**Короткий клик по окну** выводит настоящее приложение на место превью в текущем масштабе. Дальше всё работает как обычно: мышь, клавиатура, меню, перетаскивание, выделение текста. <kbd>Alt</kbd>+<kbd>V</kbd> возвращает окно на холст.

| Действие | Как |
|---|---|
| Переместить пространство | <kbd>Alt</kbd> + ПКМ и движение мыши |
| Масштаб | <kbd>Alt</kbd> + колесо, либо <kbd>Alt</kbd>+<kbd>=</kbd> / <kbd>Alt</kbd>+<kbd>-</kbd> |
| Переместить окно | ЛКМ и движение |
| Работать в окне | Короткий клик по окну |
| Вернуть окно на холст | <kbd>Alt</kbd>+<kbd>V</kbd> |
| Закрыть холст | <kbd>Alt</kbd>+<kbd>C</kbd> |

> Пока холст открыт, остальные бинды тайлинга отключены, кроме <kbd>Alt</kbd>+<kbd>C</kbd> и <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Q</kbd>.

## 🛠️ Сборка из исходников

Нужны Windows и Rust (edition 2024, свежий stable).

```
cargo build --release
```

Готовый файл: `target/release/qtil.exe`.

---

## ⚠️ Ограничения

- Только Windows.
- Окна, запущенные от администратора, не перемещаются (ограничение Windows).
- На холст не попадают свёрнутые и развёрнутые на весь экран окна.
- Если сочетание клавиш занято другой программой, Q-Tiler покажет уведомление.
- Проект ранний: сохраняйте работу перед тестами.

## 🛡️ Безопасность окон на холсте

Перед тем как убрать окна за пределы экрана, холст запускает отдельный процесс-страховку (`qtil.exe --holst-watchdog`). Если основная программа аварийно завершится, страховка вернёт окна на прежние места.
